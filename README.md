# Настільна програма обліку товарів з Flask API та Tkinter

Цей проєкт є оновленою версією настільної програми на Tkinter, яка тепер взаємодіє з локальним REST API сервером на Flask замість прямого редагування CSV-файлу.

## Особливості
- **Flask REST API сервер (`server.py`)**: реалізує CRUD-операції (`GET`, `POST`, `PUT`, `DELETE`), перевіряє типи даних (повертає `400` при невалідних полях) та зберігає дані в `data/inventory.csv`.
- **Tkinter-клієнт (`client.py`)**: взаємодіє із сервером через HTTP-запити.
- **Офлайн-режим**: якщо сервер недоступний, клієнт автоматично працює з локальним кешем (`cache.csv`), а після відновлення зв'язку дозволяє синхронізувати дані через меню.
- **Статус-бар**: інформує про стан підключення та виникаючі помилки в реальному часі.
